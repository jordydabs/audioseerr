API Access

Generate keys so other programs can connect to AudioSeerr

Send your key with every request in an X-Api-Key header (an Authorization: Bearer <key> header works too). A key acts as an admin service account with no daily request limit — it can browse, request, and approve or reject.

What a key deliberately cannot do: manage users or other API keys, read or change your Lidarr/Last.fm connection settings, or download a backup. Those need a logged-in admin session, so a leaked key can't exfiltrate your Lidarr credentials, mint more keys, or repoint AudioSeerr at another server.

Treat a key like a password: anyone who can reach your instance with it has admin-level access to requests. Revoke it here the moment it leaks.

# Example: request an artist via the API
curl -X POST "http://your-host:7575/api/requests" \
  -H "X-Api-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"artist","artistName":"Daft Punk"}'
