# AudioSeerr v2.10.1 — Docker image moves to Node 24 and Alpine 3.24

The Docker image moves off end-of-life base images. **Only the `Dockerfile` and the docs that name its base change — no application code, configuration or data format.**

## ⬆️ Before you upgrade

- **Rebuild the image:** `docker compose up -d --build`. If you keep an older `docker-compose.yml` whose image tag is still `audioseerr:2.10.0`, a plain `docker compose up -d` reuses that existing image and keeps running the old base.
- **32-bit ARM hosts (armv6/armv7) can no longer build the image.** The `node:24-alpine` images are published for amd64, arm64 and s390x only. On a 32-bit Raspberry Pi, change both `FROM` lines in the `Dockerfile` to `node:22-alpine3.24` (Node.js 22 is supported until 2027-04-30).
- Nothing changes in `.env` or `./data`; `docker-compose.yml` only gets the new image tag.

## 🔒 Security

- **The image no longer builds on end-of-life base images.** The `Dockerfile` pinned `node:20-alpine3.20`. Node.js 20 reached end-of-life on 2026-04-30 and Alpine 3.20 on 2026-04-01, and that tag was last rebuilt in May 2025 — so the image shipped Node.js 20.19.2, three security releases behind the last 20.x, on an Alpine that no longer gets fixes. Both build stages now use `node:24-alpine3.24`: Node.js 24 LTS (supported until 2028-04-30) on Alpine 3.24 (supported until mid-2028). It is still a pinned tag, not `:latest`, and the `Dockerfile` header now says where to re-check the support schedules.

## 🔧 Also

- A failed `npm ci` during the image build (seen behind a TLS-intercepting proxy) now fails the build instead of finishing with an empty `node_modules`.

## ✅ How it was checked

Built and run with the unmodified `docker-compose.yml` (`compose build` and `up -d`): healthy in about 6 seconds, `/api/health` returns the version, admin login and `/api/summary` work, read-only root filesystem, uid/gid 1000, every capability dropped, no-new-privileges and seccomp active, clean exit on SIGTERM, and data kept across a restart. 53 checks pass, and the same suite passes on `node:22-alpine3.24`. A Trivy scan showed the Alpine package findings going from 52 to 0.

## 📦 Install

```bash
git clone --branch v2.10.1 --depth 1 https://github.com/jordydabs/audioseerr.git
cd audioseerr
cp .env.example .env           # then set JWT_SECRET and ADMIN_PASS
mkdir -p ./data && sudo chown -R 1000:1000 ./data
docker compose up -d --build   # → http://localhost:7575
```

Upgrading from 2.10.0? Pull the new files, then re-run `docker compose up -d --build`.
